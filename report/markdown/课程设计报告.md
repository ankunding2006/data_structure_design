# 一、 问题描述与系统模型

## 1.1 系统物理场景与几何拓扑
本课程设计研究面向空地协同通信的无人机（UAV）基站部署与资源分配优化问题。系统模型包括 **2 架旋翼无人机**（记为 UAV 1 与 UAV 2）以及处于同一平面的 **$N$ 个离散地面用户**（$N \ge 8$）。

- **地面用户三维坐标**：第 $n$ 个地面用户所处的物理坐标为 $P_n = (a_n, b_n, 0)$，位于 $z = 0$ 的水平地面，其中 $n \in \{0, 1, \dots, N-1\}$；
- **无人机三维坐标**：两架无人机在地面上方固定高度 $G > 0$ 处巡航飞行，其空间位置分别表示为 $Q_0 = (c_1, d_1, G)$ 和 $Q_1 = (c_2, d_2, G)$；
- **空间欧氏直线距离**：第 $n$ 个用户若由第 $i$ 架无人机服务（$i \in \{0, 1\}$），二者之间的三维直线传播距离定义为：
  $$d_n = \|P_n - Q_i\| = \sqrt{(a_n - c_{i+1})^2 + (b_n - d_{i+1})^2 + G^2}$$
- **水平投影二维距离**：地面用户到无人机在水平投影面上的二维平面距离记为 $r_n$：
  $$r_n = \sqrt{(a_n - c_{i+1})^2 + (b_n - d_{i+1})^2} \implies d_n = \sqrt{r_n^2 + G^2}$$

## 1.2 信道模型与香农通信容量
空地信道通信采用自由空间路径损耗模型，信道衰减系数 $h_n$ 与直线传播距离的平方成倒数关系：
$$h_n = \frac{1}{d_n^2} = \frac{1}{r_n^2 + G^2}$$

系统的通信速率受加性高斯白噪声（AWGN）信道香农容量公式约束，且环境噪声功率归一化为 $\sigma^2 = 1$：
$$R_n = \log_2\left(1 + \frac{p_n h_n}{\sigma^2}\right) = \log_2(1 + p_n h_n)$$
其中 $p_n$ 为无人机分配给第 $n$ 个地面用户的发射功率，$R_n$ 为该用户通信所需的服务容量需求（单位：bps/Hz）。

## 1.3 课程设计任务指标
本设计严格对齐课程设计任务书的四大核心任务与两项综合评价指标：
1. **随机用户生成与链式存储**：动态生成用户坐标 $(a_n, b_n, 0)$ 及容量需求 $R_n$，并针对地面用户信道系数与容量需求设计结构体，**严格采用链式存储结构**进行动态存储与生命周期管理；
2. **两机用户划分与机理阐述**：确立将 $N$ 个地面用户划分给 2 架无人机服务的准则与算法，并在报告中对划分方法与核心原因加粗标红阐述；
3. **Minimax 空间定点优化**：在确定的用户划分下，以“最小化最大的无人机到地面用户距离”为准则确定两架无人机的水平巡航位置 $(c_i, d_i)$；
4. **满足服务容量的最小发射功率求解**：反解各用户满足容量 $R_n$ 的最小功率 $p_n$，进而求出各无人机的最小发射功率总和；
5. **图形界面演示功能**：构建工业级交互界面，生动可视化展示基站位置、覆盖外接圆、用户散点及量化统计；
6. **算法创新优化**：在基准算法之上提出能够有效压缩系统瓶颈覆盖半径与边缘用户能耗的创新算法，并给出对比实测分析。

# 二、 数学原理与理论推导

## 2.1 三维空间 Minimax 定点等价性定理及证明
题目第 3 问要求求解无人机最优部署坐标，使得无人机到其服务的所有地面用户中的最大距离最小，即 Minimax 优化问题：
$$\min_{(c, d)} \max_{n \in \mathcal{U}_i} d_n = \min_{(c, d)} \max_{n \in \mathcal{U}_i} \sqrt{(a_n - c)^2 + (b_n - d)^2 + G^2}$$

> **【定理 1】（空间 Minimax 投影等价定理）**  
> 在无人机巡航高度 $G > 0$ 保持恒定的物理条件下，最小化三维空间最远距离 $\max d_n$ 的最优水平部署坐标 $(c^*, d^*)$，与最小化二维水平投影最远距离 $\max r_n$ 的最优坐标**严格等价**，即：
> $$\arg\min_{(c, d)} \max_{n \in \mathcal{U}_i} d_n \equiv \arg\min_{(c, d)} \max_{n \in \mathcal{U}_i} r_n$$

**【严格数学证明】**：  
构造一元映射函数 $f(x) = \sqrt{x^2 + G^2}$，其自变量为水平距离 $x \in [0, +\infty)$。对 $f(x)$ 求一阶导数：
$$f'(x) = \frac{x}{\sqrt{x^2 + G^2}}$$
当物理距离 $x \ge 0$ 且高度常数 $G > 0$ 时，除 $x=0$ 点导数为 0 外，对于所有 $x > 0$ 均有 $f'(x) > 0$。因此 $f(x)$ 在定义域 $[0, +\infty)$ 上是**严格单调递增函数**。

根据复合函数极值理论，严格单调递增变换不改变有限点集上取最大值操作的极值点与顺序：
$$\max_{n \in \mathcal{U}_i} d_n = \max_{n \in \mathcal{U}_i} f(r_n) = f\left(\max_{n \in \mathcal{U}_i} r_n\right)$$
由于 $f(\cdot)$ 单调递增，对 $f(\max r_n)$ 寻优极小值与对 $\max r_n$ 寻优极小值具有完全一致的最优解集：
$$\min_{(c, d)} f\left(\max_{n \in \mathcal{U}_i} r_n\right) = f\left(\min_{(c, d)} \max_{n \in \mathcal{U}_i} r_n\right)$$
证毕。

**【工程应用推论】**：  
三维空间 Minimax 寻优问题因此精确解耦并转化为二维平面计算几何中经典的**点集最小外接圆（Minimum Enclosing Circle, MEC）**求解问题。外接圆圆心即为无人机最优平面巡航位置 $(c_i, d_i)$，外接圆半径即为该无人机最小化的最大水平覆盖半径 $r_{\max, i}$。

## 2.2 香农容量闭式反解与最小发射功率推导
为在物理层面严格满足所有地面用户的目标通信服务容量 $R_n$，等式两边进行代数逆运算：
$$R_n = \log_2(1 + p_n h_n) \implies 2^{R_n} = 1 + p_n h_n \implies p_n h_n = 2^{R_n} - 1$$
将自由空间信道衰减系数 $h_n = \frac{1}{d_n^2}$ 代入，解出单用户理论最小发射功率闭式解：
$$p_n = \frac{2^{R_n} - 1}{h_n} = (2^{R_n} - 1) \cdot d_n^2 = (2^{R_n} - 1) \cdot (r_n^2 + G^2)$$

在正交频分复用（OFDMA）或时分体制下，无人机分配给其服务子集 $\mathcal{U}_i$ 的总辐射发射功率为：
$$P_{\text{total}, i} = \sum_{n \in \mathcal{U}_i} p_n = \sum_{n \in \mathcal{U}_i} (2^{R_n} - 1) \cdot d_n^2$$
全系统双机总发射功率为：
$$P_{\text{total}} = P_{\text{total}, 0} + P_{\text{total}, 1}$$

该解析解清晰表明：**发射功率与三维直线距离的平方 $d_n^2$ 成严格正比**。通过 Minimax 算法有效压缩最远用户的空间距离 $d_n$，不仅直接缩小了系统覆盖半径，更成平方倍地抑制了边缘恶劣信道用户的发射功率暴涨。

# 三、 存储结构与核心算法设计

## 3.1 链式存储结构设计 (严格遵循数据结构课程规范)
根据课程要求 1，地面用户数据严禁使用固定大小的静态全局大数组，必须使用**链式存储结构**。在 `src/core/uav_model.h` 中设计了如下结构体：

```cpp
// 1. 二维平面点与圆 (用于计算几何与外接圆定点)
struct Point2D {
    double x, y;
};

struct Circle {
    Point2D center;
    double radius;
};

// 2. 地面用户链表节点结构体 (严格动态链式存储)
struct UserNode {
    int id;                 // 用户唯一编号 (0 ~ N-1)
    double x, y, z;         // 三维空间坐标 (an, bn, 0)
    double R;               // 目标通信容量需求 Rn (bps/Hz)
    double d;               // 到所属无人机的三维直线欧氏距离 dn (m)
    double h;               // 信道衰减系数 hn = 1 / dn^2
    double p;               // 满足容量的理论最小分配发射功率 pn (W)
    int drone_id;           // 服务无人机编号 (0 表示 UAV 1，1 表示 UAV 2)
    UserNode *next;         // 链表后继指针 (Pointer to Next Node)
};
```

### 链表内存生命周期管理
- **尾插法动态构建**：函数 `appendUserNode(id, x, y, R)` 在生成数据时动态使用 `new` 申请节点并维护指针链接，代码精炼且无冗余；
- **安全遍历与解算**：算法求解时通过移动游标指针 `cur = cur->next` 遍历链表，就地计算并更新节点内的 $d, h, p$ 属性；
- **析构彻底释放**：函数 `clearUsers()` 采用暂存指针迭代释放整个单向链表，防止内存泄漏。

## 3.2 最小外接圆定点算法 (MEC 求解器)
针对平面任意用户坐标子集 $\mathcal{P} = \{P_1, P_2, \dots, P_m\}$，依据计算几何凸包与外接圆定理，最小外接圆必然由 2 个点（以连线为直径）或 3 个非共线点（外接圆）确定。

**算法步骤**：
1. **边界情况**：若 $m=1$，圆心即该点，半径为 0；若 $m=2$，圆心为中点，半径为距离之半；
2. **两点定圆枚举**：遍历点集中所有点对 $(P_i, P_j)$，以其连线为直径作圆，判断剩余所有点是否均在圆内（允许浮点容差 $\epsilon = 10^{-6}$），若合法且半径更小则记录；
3. **三点定圆枚举**：遍历所有三点组合 $(P_i, P_j, P_k)$，排除共线点后，由解析几何闭式公式求解外接圆心与半径：
   $$D = 2[x_1(y_2 - y_3) + x_2(y_3 - y_1) + x_3(y_1 - y_2)]$$
   $$u_x = \frac{(x_1^2+y_1^2)(y_2-y_3) + (x_2^2+y_2^2)(y_3-y_1) + (x_3^2+y_3^2)(y_1-y_2)}{D}$$
   $$u_y = \frac{(x_1^2+y_1^2)(x_3-x_2) + (x_2^2+y_2^2)(x_1-x_3) + (x_3^2+y_3^2)(x_2-x_1)}{D}$$
   若点集中所有点均在圆内且半径小于当前最优值，则更新最优圆；
4. **输出**：在所有能够完全覆盖该点集的合法圆中，返回半径最小的圆心作为无人机部署坐标 $(c_i, d_i)$。

## 3.3 用户划分基线算法 (K-Means, $K=2$)
用于确立基准服务划分方案。
1. **质心初始化**：选择第 0 个点以及平面欧氏距离离它最远的用户点作为两架无人机的初始质心 $\mu_0, \mu_1$，避免初始聚类退化；
2. **迭代分配**：遍历链表节点，根据平面距离将用户划入最近质心所在簇；
3. **质心更新**：计算簇内所有用户的几何平均中心，更新质心坐标；
4. **收敛终止**：质心位移小于 $10^{-4}$ 或达到 100 次迭代后终止。

### 划分方法与原因说明（按照评分要求加粗标红）
\begin{tcolorbox}[colback=red!5!white,colframe=red!75!black,title=课程设计核心要求：用户划分方法与原因]
\textcolor{red}{\textbf{划分方法采用空间 K-Means 聚类（$K=2$）。其原因在于：通过迭代最小化同一簇内所有地面用户到几何质心的均方误差和（$\sum \|P_n - \mu_i\|^2$），将空间相邻的地面用户自动归集至同一架无人机服务，大幅缩减了单架无人机的平均空间通信距离，从统计学意义上有效降低了长距离传播带来的发射功率浪费。}}
\end{tcolorbox}

## 3.4 算法创新与改进：基于模拟退火 (SA) 的 Minimax 联合优化
### 创新机理与基准缺陷突破
- **优化准则错位**：K-Means 的数学目标是**最小化均方误差和（平均距离性能）**，并不等同于题目要求的**最小化最远边缘用户距离（极值瓶颈性能，Minimax）**。当某一区域存在孤立离群点时，K-Means 仍将其划入该簇，导致最终覆盖圆半径被该极端点严重拉伸，形成系统覆盖瓶颈；
- **模拟退火 Minimax 优化机制**：直接以全系统两架无人机覆盖外接圆半径的瓶颈值 $E = \max(r_0, r_1)$ 构建能量代价函数。利用模拟退火算法的 Metropolis 突变与跳跃特性，动态调整边缘临界用户的基站归属。

### 算法流程
1. **状态编码**：采用长度为 $N$ 的二值向量 $\mathbf{A} \in \{0, 1\}^N$ 记录各用户归属机号；
2. **能量代价函数**：
   $$E(\mathbf{A}) = \max(r_0, r_1) + 0.05 \cdot \min(r_0, r_1)$$
   若发生空簇则返回强惩罚 $10^{12}$；
3. **邻域状态扰动**：随机选取用户 $k$，执行归属翻转：$a_k \leftarrow 1 - a_k$；
4. **Metropolis 转移准则**：计算 $\Delta E = E_{\text{new}} - E_{\text{curr}}$。若 $\Delta E < 0$ 则无条件接受；若 $\Delta E \ge 0$，以概率 $P = \exp(-\Delta E / T)$ 接受劣解；
5. **退火降温调度**：初始温度 $T_0 = 50.0$，降温系数 $\alpha = 0.94$，终止温度 $T_{\min} = 10^{-2}$。

// 链表节点动态尾插构建
void UAVSystemModel::appendUserNode(int id, double x, double y, double R) {
    UserNode *node = new UserNode;
    node->id = id;
    node->x = x; node->y = y; node->z = 0.0;
    node->R = R; node->d = 0.0; node->h = 0.0; node->p = 0.0;
    node->drone_id = 0;
    node->next = nullptr;

    if (!m_head) {
        m_head = node;
    } else {
        UserNode *cur = m_head;
        while (cur->next) cur = cur->next;
        cur->next = node;
    }
    m_userCount++;
}

// 模拟退火 Minimax 创新优化算法
void UAVSystemModel::solveSimulatedAnnealing(double t_start, double t_min, double alpha) {
    if (m_userCount < 2) return;
    if (m_kmResult.assign.empty()) solveKMeans();

    std::vector<Point2D> pts(m_userCount);
    UserNode *cur = m_head;
    for (int i = 0; i < m_userCount && cur; ++i, cur = cur->next) {
        pts[i] = {cur->x, cur->y};
    }

    std::vector<int> cur_assign = m_kmResult.assign;
    std::vector<int> best_assign = cur_assign;

    // 瓶颈外接圆能量代价函数
    auto evalCost = [&](const std::vector<int> &a) -> double {
        std::vector<Point2D> p0, p1;
        for (int i = 0; i < m_userCount; ++i) {
            if (a[i] == 0) p0.push_back(pts[i]);
            else p1.push_back(pts[i]);
        }
        if (p0.empty() || p1.empty()) return 1e12; // 空簇惩罚
        Circle c0 = solveMEC(p0);
        Circle c1 = solveMEC(p1);
        return std::max(c0.radius, c1.radius) + 0.05 * std::min(c0.radius, c1.radius);
    };

    double cur_cost = evalCost(cur_assign);
    double best_cost = cur_cost;
    double T = t_start;

    // Metropolis 降温循环
    while (T > t_min) {
        for (int step = 0; step < m_userCount * 2; ++step) {
            int k = rand() % m_userCount;
            cur_assign[k] = 1 - cur_assign[k]; // 状态扰动

            double new_cost = evalCost(cur_assign);
            double delta = new_cost - cur_cost;

            if (delta < 0 || (rand() / (double)RAND_MAX) < std::exp(-delta / T)) {
                cur_cost = new_cost;
                if (cur_cost < best_cost) {
                    best_cost = cur_cost;
                    best_assign = cur_assign;
                }
            } else {
                cur_assign[k] = 1 - cur_assign[k]; // 恢复原状
            }
        }
        T *= alpha;
    }

    evaluateScheme(best_assign, m_saResult);
}

# 七、 总结与创新点归纳

1. **严格契合课程要求**：全程以动态单链表管理地面用户，杜绝静态数组冗余；
2. **严密的数学证明**：从理论上证明了空间三维 Minimax 与二维水平投影 MEC 定点的严格等价性；
3. **闭式香农功率反解**：准确解算理论最小分配发射功率，兼顾通信保障与绿色节能；
