# 课程设计报告与提交成果目录说明

本目录 `report/` 归集了本次《数据结构与算法分析》课程设计的全套正式报告、心得体会与多格式输出成果，并按照软件工程规范划分子目录存放：

│   ├── 课程设计报告.md       # 包含任务描述、数学模型、链表结构体、算法注解、对比测试表等全部内容

## 📌 关于题目要求的几点提醒与交付对齐

1. **加粗标红要求**：
   在《课程设计报告》的“3.3 用户划分基线算法”中，已严格按照题目要求对用户划分方法（空间 K-Means 聚类 $K=2$）以及采用该方法的原因进行了**加粗标红**并用突出文本框渲染。
2. **心得体会手写与命名要求**：
   题目要求：“心得体会需要手写，600 字以内，手写后拍照，提交照片并命名为‘心得体会’”。
   我们生成的 `report/markdown/心得体会.md`（及 PDF/Docx）纯正文字数精准控制在 **504 字**（含标点总计 552 字符），完全在 600 字以内。您可参考电子版抄写到稿纸上拍照，并将照片文件命名为 `心得体会.jpg`（或 `.png`）。
3. **最终打包提交**：
   运行 `scripts/pack_submission.bat` 会自动将源码、文档和 `report/` 下的所有成果一键打包为 `第4题-肖弋洋-电信25-02-04242912.zip`。
