# 方案 C：双保险架构与环境无关运行说明 (Teacher & Reviewer Guide)

> **为确保评阅教师在任意不同配置的 Windows 电脑上均可“零配置、免安装、开箱即用”地审查与验证本项目，系统采用工业级“双保险”架构设计。**

---

## 🌟 为什么无需手动配置任何环境？

在传统 C++/Qt 项目评测中，常常因为测试电脑缺少特定的编译器版本（如 MSYS2、MinGW、MSVC）或缺失特定的动态链接库（如 `Qt6Core.dll`, `libstdc++-6.dll`）而导致程序无法启动。

本项目通过 **【方案 C：双保险架构】** 彻底解决了该痛点：

```
+---------------------------------------------------------------------------------+
|                                 双保险运行体系                                   |
+----------------------------------------------------+----------------------------+
|  【第一保险：免安装发行版】                         |  【第二保险：独立纯 C++ 算法】|
|  路径：dist/bin/                                    |  路径：src/cli/main.cpp   |
|  - 已封装完整 Qt 运行库与 C++ 运行时                  |  - 纯标准 C++17 实现       |
|  - 老师电脑完全无需安装 Qt/MinGW/MSYS2              |  - 零外部图形库依赖        |
|  - 双击根目录 run.bat 秒级启动                     |  - 可在任意 IDE 中单文件编译|
+----------------------------------------------------+----------------------------+
```

---

## 🚀 方式一：免安装开箱即用运行（推荐，最省心）

解压提交的压缩包后，直接在项目根目录下双击运行：
```cmd
run.bat
```
- 控制台将弹出交互式菜单，直接按回车（默认模式 1）即可拉起 **Qt6 工业级航天遥测交互平台**；
- 亦可直接进入 `dist/bin/` 目录双击运行 `UAVCoverageOptimizer.exe`。

---

## ⚡ 方式二：纯 C++ 算法独立验证（适合机房当场测试）

若教师希望审查底层核心数据结构（链式存储、指针操作）或在仅有基础编译器的环境下快速跑数据：

### 1. 控制台快速评测：
双击 `run.bat` 选择模式 `[2]`，或在终端直接运行：
```cmd
dist\bin\uav_solver.exe 42 16 20.0 100.0
```

### 2. 任意现代编译器单文件编译：
`src/cli/main.cpp` 为高度自包含的纯 C++ 实现，无需链接任何 Qt 库：
- **GCC / Clang**：
  ```bash
  g++ -O2 -Wall src/cli/main.cpp -o my_solver.exe
  ./my_solver.exe
  ```
- **MSVC (Visual Studio 命令行)**：
  ```cmd
  cl /EHsc /O2 src\cli\main.cpp /Fe:my_solver.exe
  my_solver.exe
  ```
- **Dev-C++ / Code::Blocks / CLion**：直接新建控制台项目，将 `src/cli/main.cpp` 加入即可一键点绿箭头运行。

---

## 🛠️ 方式三：完整源码二次开发与构建（面向开发人员）

若开发者机器上已安装 Qt6 与 CMake，可使用根目录下的编译脚本重新构建：
```cmd
build.bat
```
会自动调用 CMake + Ninja 进行全工程重构编译，并将新二进制输出至 `build/` 目录。
