## 1. 链式存储结构设计 (严格遵循数据结构课程规范)

根据课程设计硬性指标要求，地面用户信道系数与所需服务容量必须采用**链式存储结构**进行动态管理。在 `src/core/uav_model.h` 中定义如下核心数据结构：

```cpp
// 1. 二维平面点与圆 (用于计算几何与外接圆定点)
struct Point2D {
    double x, y;
};

struct Circle {
    Point2D center;
    double radius;
};

// 2. 地面用户链表节点结构体 (严格动态链式存储)
struct UserNode {
    int id;                 // 用户唯一编号 (0 ~ N-1)
    double x, y, z;         // 三维空间坐标 (an, bn, 0)
    double R;               // 目标通信容量需求 Rn (bps/Hz)
    double d;               // 到所属无人机的三维直线欧氏距离 dn (m)
    double h;               // 信道衰减系数 hn = 1 / dn^2
    double p;               // 满足容量的理论最小分配发射功率 pn (W)
    int drone_id;           // 服务无人机编号 (0 表示 UAV 1，1 表示 UAV 2)
    UserNode *next;         // 链表后继指针 (Pointer to Next Node)
};

// 3. 无人机实体结构体
struct Drone {
    int id;                 // 无人机编号
    double x, y, z;         // 空间巡航坐标 (ci, di, G)
    double max_r;           // 水平覆盖半径 r_max (m)
    double total_power;     // 服务该机子集所有用户的最小总发射功率 (W)
    int user_count;         // 服务的用户总数
};
```

### 链表生命周期管理规范
- **动态创建与尾插法**：`appendUserNode()` 在生成随机用户数据时依次申请堆内存，并通过尾指针链入单链表。
- **内存回收机制**：`clearUsers()` 在重新生成或析构时，通过单循环遍历完整 `delete` 链表上的所有节点，杜绝内存泄漏。

## 2. 算法一：精确几何最小外接圆定点算法 (MEC Solver)

针对用户点集 $\mathcal{P} = \{P_1, P_2, \dots, P_m\}$，求解覆盖所有点的最小外接圆 $(C, r)$。

### 2.1 算法原理
由计算几何基本定理，平面有限点集的唯一最小外接圆必然满足以下两类充分必要条件之一：
1. **两点定圆**：圆以点集中某两点的连线段为直径，其余所有点均落在该圆内部或边界上；
2. **三点定圆**：圆为点集中某三个非钝角三角形顶点的外接圆，其余所有点均在圆内。

### 2.2 核心代码实现 (`src/core/uav_model.cpp`)
```cpp
Circle UAVSystemModel::solveMEC(const std::vector<Point2D> &pts) {
    int n = static_cast<int>(pts.size());
    if (n == 0) return {{0, 0}, 0};
    if (n == 1) return {pts[0], 0};
    if (n == 2) {
        Point2D c = {(pts[0].x + pts[1].x) / 2.0, (pts[0].y + pts[1].y) / 2.0};
        return {c, std::hypot(pts[0].x - pts[1].x, pts[0].y - pts[1].y) / 2.0};
    }

    Circle best = {{0, 0}, 1e18};

    // 1) 两点定圆判定（以两点连线为直径）
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            Point2D c = {(pts[i].x + pts[j].x) / 2.0, (pts[i].y + pts[j].y) / 2.0};
            double r = std::hypot(pts[i].x - pts[j].x, pts[i].y - pts[j].y) / 2.0;
            if (r >= best.radius) continue;

            bool ok = true;
            for (int k = 0; k < n; ++k) {
                if (std::hypot(pts[k].x - c.x, pts[k].y - c.y) > r + 1e-6) {
                    ok = false;
                    break;
                }
            }
            if (ok) best = {c, r};
        }
    }

    // 2) 三点定圆判定（三角形外接圆闭式方程）
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            for (int k = j + 1; k < n; ++k) {
                double x1 = pts[i].x, y1 = pts[i].y;
                double x2 = pts[j].x, y2 = pts[j].y;
                double x3 = pts[k].x, y3 = pts[k].y;
                double D = 2.0 * (x1 * (y2 - y3) + x2 * (y3 - y1) + x3 * (y1 - y2));
                if (std::fabs(D) < 1e-7) continue; // 三点共线跳过

                double ux = ((x1*x1 + y1*y1)*(y2 - y3) + (x2*x2 + y2*y2)*(y3 - y1) + (x3*x3 + y3*y3)*(y1 - y2)) / D;
                double uy = ((x1*x1 + y1*y1)*(x3 - x2) + (x2*x2 + y2*y2)*(x1 - x3) + (x3*x3 + y3*y3)*(x2 - x1)) / D;
                double r = std::hypot(x1 - ux, y1 - uy);

                if (r >= best.radius) continue;

                bool ok = true;
                for (int m = 0; m < n; ++m) {
                    if (std::hypot(pts[m].x - ux, pts[m].y - uy) > r + 1e-6) {
                        ok = false;
                        break;
                    }
                }
                if (ok) best = {{ux, uy}, r};
            }
        }
    }
    return best;
}
```

## 3. 算法二：基线划分算法 —— K-Means 聚类 ($K=2$)

### 3.1 划分流程
1. **质心初始化**：选择第 0 个点以及平面欧氏距离离它最远的用户点作为两架无人机的初始质心 $\mu_0, \mu_1$（确保质心充分分散）。
2. **归属迭代**：遍历所有用户，根据到质心的二维距离分配到最近的簇中（`assign[n] = 0 或 1`）。
3. **质心更新**：计算簇内所有用户的几何平均中心，作为新质心。
4. **收敛终止**：两次迭代质心位移小于阈值 $10^{-4}$ 或达到最大步数（100次）退出。

### 3.2 划分依据及原因（报告加粗标红要求）
> **划分方法采用空间 K-Means 聚类（$K=2$）。其原因在于：通过迭代最小化同一簇内所有地面用户到几何质心的均方误差和（$\sum \|P_n - \mu_i\|^2$），将空间相邻的地面用户自动归集至同一架无人机服务，大幅缩减了单架无人机的平均空间通信距离，从统计学意义上有效降低了长距离传播带来的发射功率浪费。**

## 4. 算法三：创新改进算法 —— 基于模拟退火 (SA) 的 Minimax 联合优化

### 4.1 创新机理与基准缺陷突破
- **K-Means 准则失配**：K-Means 的优化目标是**均方误差和（平均性能）**，并不等同于题目要求的**最小化最远边缘用户距离（极值性能，Minimax）**。当某一区域存在个别离群孤立点时，K-Means 仍将其划入该簇，导致最终覆盖圆半径被该极端点严重拉伸，形成系统覆盖瓶颈。
- **直接面向瓶颈优化的 SA**：直接以全系统双机覆盖外接圆半径的瓶颈值 $E = \max(r_0, r_1)$ 构建能量函数，利用模拟退火的全局跳跃与突变能力，动态调整边缘临界用户的基站归属。

### 4.2 能量函数与 Metropolis 准则设计
1. **状态空间**：划分向量 $\mathbf{A} = [a_0, a_1, \dots, a_{N-1}] \in \{0, 1\}^N$。
2. **能量代价函数**：
   $$E(\mathbf{A}) = \max(r_0, r_1) + 0.05 \cdot \min(r_0, r_1)$$
   主目标压制两机瓶颈覆盖半径，辅助项促使非瓶颈机半径同步收敛。若产生空簇，返回强惩罚 $10^{12}$。
3. **邻域扰动操作**：随机选择一个边缘用户索引 $k$，执行状态翻转：
   $$a_k \leftarrow 1 - a_k$$
4. **Metropolis 转移接受准则**：
   计算能量差 $\Delta E = E_{\text{new}} - E_{\text{curr}}$：
   $$P_{\text{accept}} = \begin{cases} 1, & \Delta E < 0 \\ \exp\left(-\frac{\Delta E}{T}\right), & \Delta E \ge 0 \end{cases}$$
5. **降温调度**：初始温度 $T_0 = 50.0$，衰减系数 $\alpha = 0.94$，终止温度 $T_{\min} = 10^{-2}$。
