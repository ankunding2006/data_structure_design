# 模块 04：软件架构与 Qt6 工业级 GUI 设计

---

## 1. 软件工程分层架构设计

为了保证软件工程规范的高质量与高内聚低耦合，项目采用经典的 **MVC (Model-View-Controller)** 软件分层架构：

```
+-------------------------------------------------------------+
|                      展示层 (View / UI)                      |
|   - MainWindow: 菜单栏、工具栏、折叠侧边栏、遥测详情卡片       |
|   - UAVCanvas: QPainter 硬件加速 2D 矢量交互画布、双屏分栏   |
+------------------------------+------------------------------+
                               | Qt 信号与槽 (Signals & Slots)
+------------------------------v------------------------------+
|                     控制/桥接层 (Controller)                 |
|   - 参数解析、仿真调度、事件过滤、异步动效编排、成果导出管理   |
+------------------------------+------------------------------+
                               | 纯 C++ 原生方法调用
+------------------------------v------------------------------+
|                    核心算法与数据层 (Model)                  |
|   - UserNode* 单向链表管理 (动态申请/析构)                   |
|   - 最小外接圆定点 (MEC Solver)                              |
|   - K-Means 基线聚类与模拟退火 Minimax 全局优化引擎          |
+-------------------------------------------------------------+
```

## 3. 核心界面组件实现要点

### 3.1 四旋翼无人机矢量拟物绘制 (`src/gui/canvas.cpp`)
告别传统粗糙的方块图元，通过 `QPainterPath` 矢量构建具备机械质感的四旋翼无人机俯视图标：
1. **底盘发光晶体**：`QRadialGradient` 径向渐变模拟航电设备外发光；
2. **十字悬臂结构**：绘制对角交错的 4 条高强度支撑臂；
3. **旋翼桨叶圆盘**：在悬臂四角绘制 4 个独立小圆环，带透明度填充；
4. **中心航电舱**：中心实心机身与高对比度标识。

### 3.2 动态自绘 HUD 遥测悬浮窗 (Floating HUD Card)
不使用系统卡顿的简单原生 Tooltip，而是通过捕获 `mouseMoveEvent` 自绘半透明毛玻璃浮层：
- 动态显示目标用户坐标 $(x, y, 0)$、容量需求 $R_n$、服务基站、三维空间距离 $d_n$、信道衰减系数 $h_n$、理论最小发射功率 $p_n$；
- 若用户属于 SA 重分配点，额外高亮显示“**SA 智能重分配 (离群点收敛)**”分析标签；
- 具备屏幕边界自动碰撞检测，防止弹窗溢出视窗。

### 3.3 画布与数据审查表双向联动
- **画布 $\rightarrow$ 表格**：在二维画布上鼠标左键点击任意用户点，底部 `QTableWidget` 自动平滑滚动并高亮选中该行，右侧【节点遥测监视卡片】同步刷新；
- **表格 $\rightarrow$ 画布**：在底部数据表中点击某一行，画布上对应用户节点立即激活**正弦周期波动的金色弹性脉冲光环**（`m_pulsePhase` 驱动）。

### 3.4 成果一键导出模块
- **超分辨率图像保存**：通过 `QPixmap(size() * 2)` 进行 2 倍超采样离屏渲染，一键导出用于打印报告的 300 DPI 无损对比效果图；
- **数据报表导出**：支持将所有链表节点的计算结果一键导出为标准逗号分隔文件（`*.csv`）与结构化 JSON（`*.json`）。
